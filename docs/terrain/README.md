# Comptes rendus de visites de laboratoires

Un fichier par visite : `AAAA-MM-JJ-nom-du-labo.md`.

À noter pendant la visite, sans filtrer :

- Combien de travaux par jour, combien de techniciens, combien de cabinets clients.
- Le chemin réel d'un travail, de la réception à la livraison, étape par étape.
- Ce qui est écrit sur papier, et pourquoi ça n'est pas dans leur logiciel.
- Ce qui les agace dans l'outil actuel, avec leurs mots.
- Ce qu'ils font à l'établi, gants aux mains : combien de manipulations avant de
  pouvoir valider une étape.
- Comment ils facturent aujourd'hui, et quelles erreurs arrivent.
- Qui décide d'acheter un logiciel, et combien ils paient actuellement.

Une photo de leurs fiches papier vaut une heure d'entretien.
