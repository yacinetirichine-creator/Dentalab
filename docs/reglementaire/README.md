# Vérifications réglementaires

Y déposer les comptes rendus, e-mails et avis des professionnels consultés.
Quatre sujets, détaillés au §4 du cahier des charges :

| Sujet | Qui consulter | Statut |
|---|---|---|
| Dispositifs médicaux sur mesure (règlement UE 2017/745) | Juriste santé ou consultant qualité | ⬜ à faire |
| Facturation électronique (Factur-X, plateforme agréée) | Expert-comptable | ⬜ à faire |
| TVA sur les prothèses dentaires | Expert-comptable | ⬜ à faire |
| RGPD et hébergement HDS | Juriste / DPO | ⬜ à faire |

**Rien de ce qui est écrit dans le cahier des charges sur ces quatre sujets n'a été
vérifié par un professionnel.** Ce sont des éléments de cadrage, pas un avis juridique.
